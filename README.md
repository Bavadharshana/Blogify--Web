# **Blogify – A Modern Full-Stack Blogging Platform**

Blogify is a full-stack blogging platform that I built to make creating, editing, and reading blogs simple and fast.  
It features a clean, responsive UI and a smooth writing experience powered by modern web technologies.

---

## **🌐 Live Demo**

👉 **Live Website:** https:// [Click Here!!](https://blogify--web.vercel.app/)  

---

# **✨ Features**

- 📝 Create, edit, and publish blog posts  
- 📚 View all posts in a clean, minimal UI  
- 🔎 Search and filter blogs  
- 🌙 Light & dark mode   
- 🚀 Fast, responsive, optimized front-end  
- 🔐 Authentication support 

---

# **🛠️ Tech Stack**

- **React**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **shadcn-ui**

# **📦 Installation & Local Development**

To run Blogify locally, make sure Node.js and npm are installed.  

### **🚀 Steps**

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Move into the project folder
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
